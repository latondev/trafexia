# Trafexia - 모바일 네트워크 트래픽 인터셉트 및 분석 도구

모바일 디바이스에서 발생하는 HTTP/HTTPS 트래픽을 차단, 분석 및 수정할 수 있는 강력한 데스크톱 애플리케이션입니다. Electron, Vue 3, TypeScript로 개발되었습니다.

Trafexia는 모바일 앱 보안 테스트, 리버스 엔지니어링, API 디버깅을 위한 포괄적인 도구를 제공하며, SSL 고정 우회(SSL Pinning Bypass), 가상 응답(Mocking), 트래픽 매핑(Map Rules) 등의 고난도 기능을 지원합니다.

---

## ✨ 핵심 기능

### 🔐 SSL/TLS 보안 우회 (SSL Bypass)
- **기본 탑재 우회 스크립트** - OkHttp3, Conscrypt, WebView, Flutter, React Native 등을 내장 지원.
- **APK 패치 (APK Patching)** - 루팅되지 않은 기기에서도 APK 파일에 직접 우회 스크립트 주입 가능.
- **Frida Gadget 통합** - Frida를 사용해 동적으로 코드를 주입하고 런타임 후킹 수행.

### 📊 실시간 트래픽 분석
- **실시간 요청 캡처** - HTTP/HTTPS 요청을 실시간으로 차단하여 보여줍니다.
- **타임라인 시각화** - 요청 분산도와 빈도를 직관적인 차트로 시각화.
- **고급 필터링** - HTTP 메소드, 응답 코드, 호스트, URL 경로 등으로 상세 필터링 지원.
- **비교 분석 (Diff)** - 원본 요청과 수정된 요청의 차이점을 좌우 분할 화면으로 쉽게 비교.

### 🎯 요청 수정 및 제어 (Manipulation)
- **경로 매핑 (Map Rules)** - 정규식을 사용하여 특정 요청을 다른 URL 또는 로컬 파일로 리다이렉트.
- **모의 응답 (Mock Responses)** - 커스텀 상태 코드, 헤더 및 응답 본문이 적용된 가상 응답 생성.
- **요청 빌더 (Composer)** - 직접 HTTP 요청을 작성하고 발송하여 API 테스트 수행.
- **대역폭 제한 (Throttling)** - 지연 시간 및 통신 속도를 설정하여 느린 네트워크 환경에서의 앱 동작 시뮬레이션.

## 🚀 시작하기

### 사전 요구사항
- **Node.js** 18 버전 이상
- **Android SDK** (APK 패치 기능 사용 시 필요)
- **macOS / Windows / Linux**

### 설치 및 개발 모드 실행
```bash
# 저장소 복제
git clone https://github.com/danieldev23/trafexia.git
cd trafexia

# 의존성 패키지 설치
npm install

# 개발 서버 시작
npm run dev
```

### 프로덕션 빌드 (배포용 패키징)
```bash
# 실행 중인 플랫폼에 맞게 빌드
npm run build

# macOS (Intel CPU) 빌드
npm run build:mac

# macOS (Apple Silicon M1/M2/M3) 빌드
npm run build:mac-arm

# Windows 빌드
npm run build:win
```
빌드 패키지는 `dist-electron/` 폴더에 생성됩니다.

## 📖 모바일 디바이스 설정 가이드

### Android 설정 방법

#### 1단계: 프록시 설정
1. **설정** → **Wi-Fi**를 엽니다.
2. 연결된 Wi-Fi를 길게 눌러 **네트워크 수정**을 선택합니다.
3. **고급 옵션**을 펼칩니다.
4. **프록시**를 **수동**으로 설정합니다.
5. Trafexia 화면에 표시된 **프록시 IP 주소**와 **포트**를 입력합니다.
6. **저장**을 터치합니다.

#### 2단계: CA 인증서 설치
1. Trafexia 앱에서 QR 코드나 다운로드 링크를 통해 CA 인증서를 저장합니다.
2. **설정** → **보안** → **암호화 및 사용자 인증 정보**로 이동합니다.
3. **저장소에서 설치**를 누릅니다.
4. 다운로드한 인증서 파일을 선택하여 설치를 마칩니다.

---

### iOS 설정 방법

#### 1단계: 프록시 설정
1. **설정** → **Wi-Fi**를 선택합니다.
2. 연결된 Wi-Fi 오른쪽에 있는 **(i)** 버튼을 누릅니다.
3. 아래로 끝까지 스크롤하여 **프록시 구성**을 탭하고 **수동**을 선택합니다.
4. Trafexia에 나오는 **서버/IP**와 **포트**를 입력합니다.
5. **저장**을 선택합니다.

#### 2단계: CA 인증서 설치 및 신뢰 설정
1. iOS 기기에서 Trafexia의 다운로드 링크나 QR 코드를 이용해 CA 인증서 프로파일을 다운로드합니다.
2. **설정** → **프로파일이 다운로드됨** 메뉴로 이동하여 설치를 진행합니다.
3. **설정** → **일반** → **정보** → **인증서 신뢰 설정**으로 이동합니다.
4. Trafexia CA 인증서의 **루트 인증서 전체 신뢰 활성화** 스위치를 켭니다.
