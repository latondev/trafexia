# Trafexia - モバイルデバイスネットワークトラフィック解析・インターセプトツール

モバイルデバイスからの HTTP/HTTPS トラフィックをインターセプト、分析、および改ざんするための強力なデスクトップアプリケーションです。Electron、Vue 3、TypeScript で構築されています。

Trafexia は、SSL ピンニングバイパス、レスポンスモック（Mocking）、トラフィックマッピング（Map Rules）などの高度な機能により、モバイルアプリのセキュリティテスト、リバースエンジニアリング、および API デバッグを支援します。

---

## ✨ 主な機能

### 🔐 SSL/TLS セキュリティバイパス
- **組み込みのバイパススクリプト** - OkHttp3, Conscrypt, WebView, Flutter, React Native などを標準サポート。
- **APK パッチ適用** - root化されていないデバイスでも、バイパススクリプトを直接 APK に埋め込み可能。
- **Frida Gadget の統合** - Frida を使用した動的コードインジェクションおよびランタイムフック。

### 📊 リアルタイムトラフィック分析
- **ライブキャプチャ** - HTTP/HTTPS リクエストをリアルタイムでキャプチャし表示。
- **タイムライン表示** - リクエストの分布と頻度を視覚的にチャート表示。
- **高度なフィルタリング** - HTTP メソッド、ステータスコード、ホスト、URL パスなどによる絞り込み。
- **リクエスト比較 (Diff)** - 元のリクエストと変更されたリクエストの差異を左右分割表示で簡単に比較。

### 🎯 リクエスト改ざん・モック
- **トラフィックマッピング (Map Rules)** - 正規表現を使用して、リクエストを別の URL またはローカルファイルにリダイレクト。
- **レスポンスモック (Mock Responses)** - カスタムのステータスコード、ヘッダー、およびレスポンスボディを持つモックを簡単に作成。
- **リクエストコンポーザー (Composer)** - 手動で HTTP リクエストを作成し、API テストを実行。
- **帯域制御 (Throttling)** - 遅延や通信速度制限を設定し、弱電界・弱ネット環境下でのアプリ動作をシミュレート。

## 🚀 はじめに

### 前提条件
- **Node.js** 18 以上
- **Android SDK** (APK パッチ機能で使用)
- **macOS / Windows / Linux**

### 開発モードでのインストールと起動
```bash
# リポジトリをクローン
git clone https://github.com/danieldev23/trafexia.git
cd trafexia

# 依存パッケージをインストール
npm install

# 開発用ローカルサーバーを起動
npm run dev
```

### パッケージのビルド (製品版)
```bash
# 実行中プラットフォーム用ビルド
npm run build

# macOS (Intel) 用ビルド
npm run build:mac

# macOS (Apple Silicon M1/M2/M3) 用ビルド
npm run build:mac-arm

# Windows 用ビルド
npm run build:win
```
ビルド結果は `dist-electron/` フォルダに出力されます。

## 📖 モバイルデバイス設定ガイド

### Android の設定手順

#### ステップ 1: プロキシ設定
1. **設定** → **Wi-Fi** を開きます。
2. 接続中のネットワークを長押しし、**ネットワークの変更** を選択します。
3. **詳細設定** を展開します。
4. **プロキシ** を **手動** に設定します。
5. Trafexia に表示されている **プロキシの IP アドレス** と **ポート** を入力します。
6. **保存** をタップします。

#### ステップ 2: CA 証明書のインストール
1. Trafexia クライアントから CA 証明書をダウンロードします（QR コードまたはリンク）。
2. **設定** → **セキュリティ** → **暗号化と認証情報** を開きます。
3. **ストレージからインストール** をタップします。
4. ダウンロードした証明書ファイルを選択し、インストールします。

---

### iOS の設定手順

#### ステップ 1: プロキシ設定
1. **設定** → **Wi-Fi** を開きます。
2. 接続中の Wi-Fi の横にある **(i)** マークをタップします。
3. 一番下までスクロールし、**プロキシ構成** をタップして **手動** を選択します。
4. Trafexia に表示されている **サーバ / IP** と **ポート** を入力します。
5. **保存** をタップします。

#### ステップ 2: CA 証明書のインストールと信頼設定
1. iOS デバイスから QR コードまたはダウンロードリンクを使用し、CA 証明書プロファイルをダウンロードします。
2. **設定** → **プロファイルがダウンロードされました** をタップし、インストールします。
3. 次に、**設定** → **一般** → **情報** → **証明書信頼設定** を開きます。
4. Trafexia CA 証明書の **ルート証明書を全面的に信頼する** スイッチをオンにします。

- **テスト終了後は、デバイスから必ず CA 証明書を削除してください。**
