# Trafexia - Инструмент перехвата и анализа трафика мобильных устройств

Мощное десктопное приложение для перехвата, анализа и изменения HTTP/HTTPS трафика с мобильных устройств. Построено на базе Electron, Vue 3 и TypeScript.

Trafexia предоставляет полный спектр инструментов для тестирования безопасности мобильных приложений, обратной разработки (reverse engineering) и отладки API с расширенными возможностями, такими как обход SSL-pinning, имитация ответов (mocking), перенаправление трафика (map rules) и многое другое.

---

## ✨ Основные возможности

### 🔐 Обход защиты SSL/TLS (SSL Bypass)
- **Встроенные скрипты обхода** - Поддержка OkHttp3, Conscrypt, WebView, Flutter, React Native и др.
- **Модификация APK (APK Patching)** - Внедряйте скрипты обхода непосредственно в APK файлы без необходимости рутирования устройства.
- **Интеграция с Frida Gadget** - Динамическое внедрение кода с использованием Frida для перехвата функций в реальном времени.

### 📊 Анализ трафика в реальном времени
- **Живой перехват** - Перехватывайте и отображайте HTTP/HTTPS запросы в режиме реального времени.
- **Визуализация на временной шкале (Timeline)** - Отслеживайте распределение и частоту запросов в виде интерактивного графика.
- **Расширенные фильтры** - Фильтруйте по HTTP-методу, коду состояния, хосту, пути URL и т. д.
- **Сравнение запросов (Diff)** - Интерфейс параллельного сравнения различий между исходным и измененным запросами.

### 🎯 Модификация запросов
- **Перенаправление (Map Rules)** - Перенаправляйте запросы на другие URL с помощью регулярных выражений (Regex).
- **Имитация ответов (Mock Responses)** - Создавайте поддельные ответы с настраиваемыми кодами состояния, заголовками (headers) и телом ответа (body).
- **Конструктор запросов (Composer)** - Создавайте и отправляйте HTTP-запросы вручную для тестирования API.
- **Ограничение пропускной способности (Throttling)** - Симулируйте медленное сетевое подключение для проверки производительности.

## 🚀 Быстрый старт

### Требования
- **Node.js** 18 или выше
- **Android SDK** (требуется для функций модификации APK)
- **macOS / Windows / Linux**

### Установка и запуск в режиме разработки
```bash
# Клонировать репозиторий
git clone https://github.com/danieldev23/trafexia.git
cd trafexia

# Установить зависимости
npm install

# Запустить сервер разработки
npm run dev
```

### Сборка для продакшена
```bash
# Сборка под текущую платформу
npm run build

# Сборка для macOS (Intel)
npm run build:mac

# Сборка для macOS (Apple Silicon - M1/M2/M3)
npm run build:mac-arm

# Сборка для Windows
npm run build:win
```
Собранные исполняемые файлы будут находиться в папке `dist-electron/`.

## 📖 Руководство по настройке мобильных устройств

### Настройка на Android

#### Шаг 1: Настройка прокси
1. Откройте **Настройки** → **Wi-Fi**.
2. Удерживайте нажатие на имя подключенной сети и выберите **Изменить сеть**.
3. Нажмите **Дополнительные параметры**.
4. Установите **Прокси** в значение **Вручную**.
5. Введите **IP прокси** и **Порт** (отображаемые в Trafexia).
6. Нажмите **Сохранить**.

#### Шаг 2: Установка сертификата CA
1. Загрузите сертификат CA из Trafexia (с помощью QR-кода или прямой ссылки).
2. Перейдите в **Настройки** → **Безопасность** → **Шифрование и учетные данные**.
3. Выберите **Установка из накопителя**.
4. Выберите загруженный файл сертификата для завершения установки.

---

### Настройка на iOS

#### Шаг 1: Настройка прокси
1. Откройте **Настройки** → **Wi-Fi**.
2. Нажмите иконку **(i)** рядом с вашей подключенной сетью.
3. Прокрутите вниз до пункта **Настройка прокси** и выберите **Вручную**.
4. Введите **Сервер (IP)** и **Порт**, указанные в Trafexia.
5. Нажмите **Сохранить**.

#### Шаг 2: Установка и доверие сертификату CA
1. Используйте iOS-устройство для загрузки профиля сертификата CA по ссылке из Trafexia.
2. Откройте **Настройки** → **Профиль загружен** и выполните установку.
3. Перейдите в **Настройки** → **Основные** → **Об этом устройстве** → **Доверие сертификатам**.
4. Включите полное доверие для сертификата Trafexia CA.

## 🔒 Безопасность и конфиденциальность
- **Используйте этот инструмент только для разработки и тестирования безопасности на ваших собственных устройствах или авторизованных приложениях.**
- **Обязательно удалите сертификат CA с устройства после завершения тестирования.**
- Не используйте этот инструмент для незаконных действий или несанкционированного перехвата данных.
